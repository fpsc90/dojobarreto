# Dojo Barreto — site

Site publicado em https://www.dojobarreto.com.br/ pelo GitHub Pages.

Estes arquivos são **gerados** pelo projeto do site (`npm run build:github`). Não edite aqui:
altere o `index.html` do projeto, rode `npm run verificar:github` e substitua o conteúdo deste repositório.

- `CNAME`: domínio próprio (www.dojobarreto.com.br)
- `.nojekyll`: publica os arquivos exatamente como estão
- `robots.txt` e `sitemap.xml`: orientação para buscadores
- `404.html`: página para endereços inexistentes
